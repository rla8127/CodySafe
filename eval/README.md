# eval: 판정기 평가와 시연 자료

## 1. 판정기 라벨 붙이기 (호연, 06:30–07:00)

**1)** `judge_candidates.csv`를 복사해 `judge_holdout.csv`로 저장합니다. 그다음 `label` 칸에 `정답`·`중답`·`오답` 중 하나를 적습니다. `memo`는 비워도 됩니다.

- A. 정답: 끊기, 분명한 거절, 공식 번호(1301·1332·은행 대표번호·택배 앱) 또는 가족(원래 번호·암구호)으로 확인하기, 신고(112·118)
- B. 중답: 되묻거나 망설이지만 아직 따르지는 않은 답
- C. 오답: 따르기, 정보 주기(인증번호·계좌·카드·신분증·비밀번호), 송금·상품권·앱 설치·링크 누르기에 동의하기, 비밀 지키기, 끊지 않기
- D. 미끼 인증번호는 모든 장면에서 `340891`입니다. 장면 문맥은 `scene` 칸에 있습니다.

**2)** 30줄 이상에 라벨이 붙으면 평가할 수 있습니다. 60줄 모두 붙이면 가장 좋습니다.

**3)** 저장소 루트에서 `server/.venv/bin/python scripts/eval_judge.py`를 실행합니다. 결과는 `eval/judge_report.md`에 나옵니다.

**4)** 라벨을 붙인 뒤에는 이 파일을 보면서 판정 규칙이나 프롬프트를 고치지 않습니다(R-005).

## 2. 파일

- A. `judge_candidates.csv`: 어르신 답 후보 60개. 판정 규칙을 보지 않은 별도 에이전트가 장면 대사만 보고 썼습니다. 라벨 칸은 비어 있습니다.
- B. `judge_holdout.csv`: 호연이 라벨을 붙여 고정한 평가 파일입니다.
- C. `judge_report.md`: 정확도, 혼동 행렬, 위험한 답을 안전으로 본 수.
- D. `latency.md`: 전화 훈련에서 잰 차례별 음성 인식 시간과 판정 시간.
- E. `screens/`: 시연 화면 캡처.
- F. `synthetic_call.wav`: 탐지 시연용 **합성** 사기 통화. 실제 사람 목소리가 아니며 기관 사칭 대본을 TTS로 읽은 것입니다.
