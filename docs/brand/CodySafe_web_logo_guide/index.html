세로형 파일 다운로드

정방형 심볼

카멜레온·자물쇠 심볼만 사용합니다. 앱 타일, 프로필과 좁은 영역에 적합합니다.

심볼 파일 다운로드

파비콘 후보

파비콘 후보 다운로드

세로형과 심볼형은 원본 이미지를 잘라 배치한 시안입니다. 로고의 형상과 글자를 새로 그리지 않았습니다.

03 / SIZE & SPACING

크기와 여백

보호 공간   심볼의 높이를 H로 볼 때 로고 주위에 최소 0.15H의 여백을 제안합니다.
가로형   헤더에서 폭 약 160–220 CSS px부터 시험하고, 작게 표시할 때는 자물쇠·문자 가독성을 확인합니다.
세로형   폭 약 180 CSS px 이상부터 시험합니다. 수치는 확정 규격이 아닌 출발점입니다.
심볼   64px 이상을 우선 권장합니다. 32px 이하에서는 열쇠 구멍과 세부 선이 사라질 수 있습니다.
파비콘   16px과 32px 실제 표시 크기, 밝은 탭과 어두운 탭에서 확인하세요. 소형 전용 단순화는 별도 디자인 작업이 필요합니다.
배경   검정 로고는 밝고 단순한 배경 위에 놓습니다. 어두운 배경에는 충분한 대비를 가진 밝은 패널을 사용합니다.
금지   가로세로 비율 변경, 회전, 그림자 추가, 심볼·글자 임의 재구성, 복잡한 배경 위 직접 사용.
