# CodySafe 로고 아이덴티티 가이드

**디자인 제안 · 2026.10 · 초안**

## 1. 브랜드의 중심

**한 번 더 살피고, 함께 지킵니다.**

CodySafe는 디지털 사기를 알아보고 대응하도록 돕는 서비스로 기획되었습니다. 카멜레온 로고는 주변을 세심하게 살피는 태도와 상황에 맞게 대응하는 유연함을, 로고 안의 자물쇠 형태는 보호를 상징합니다. UREAKA는 로고에 담긴 팀 이름이며 CodySafe는 서비스 이름입니다.

- **세심함:** 놓치기 쉬운 위험 단서를 살핍니다.
- **명확함:** 어려운 내용을 짧고 이해하기 쉽게 설명합니다.
- **함께함:** 혼자 판단하기 어려울 때 가족과 함께 대응하도록 돕습니다.

제안 문구: **찍기 전에, 한 번 더 살피다.** 이 문구는 QR 검사 관련 캠페인에 적합합니다. 전체 서비스의 대표 문구로는 **안심을 함께 만드는 습관**을 제안합니다.

## 2. 로고 구성과 역할

- **기본 로고:** 기존 카멜레온 UREAKA 로고. 비율과 실루엣, 꼬리와 자물쇠 음각을 유지합니다.
- **서비스명:** CodySafe를 일반 텍스트로 함께 표기합니다. 로고의 글자를 CodySafe로 임의 교체하지 않습니다.
- **관계 표기 예시:** `CodySafe` / `by Team UREAKA`. 필요한 경우 카멜레온 로고와 서비스명을 나란히 배치하되 서로 겹치지 않게 합니다.
- **목업의 방패 아이콘:** 현재 화면에서 사용 중인 별도 UI 아이콘입니다. 카멜레온 로고를 상단에 적용할 위치와 두 요소를 함께 쓸지는 시안 검토 후 확정합니다.
- **앱 아이콘:** 현재 로고는 세부 요소가 많아 작은 크기에서 뭉개질 수 있습니다. 임의로 일부를 잘라 사용하지 말고, 별도 소형 심볼을 제작하고 검증합니다.

## 3. 기본 사용 규칙

- 밝은 단색 배경에는 검정 로고, 어두운 단색 배경에는 흰색 반전형을 사용합니다. 음각 부분은 배경이 보이도록 유지합니다.
- 보호 공간은 로고 높이의 **15% 이상**을 사방에 확보하는 것을 제안합니다. 텍스트와 다른 그래픽을 이 영역 밖에 둡니다.
- 임시 최소 크기는 **디지털 폭 240px, 인쇄 폭 60mm**입니다. 매체와 출력 방식에 따라 자물쇠, 입 부분과 꼬리를 실제 크기로 확인한 뒤 확정합니다.
- 늘이기, 기울이기, 외곽선 추가, 음각 메우기, 복잡한 사진 위 직접 배치를 피합니다. 사진 위에 써야 한다면 단색 바탕을 놓습니다.
- SVG를 기본 원본으로 사용합니다. 인쇄용 PDF/EPS는 제작 업체의 출력 환경에 맞춰 확인합니다. 자동 추적한 벡터이므로 확대 인쇄 전 윤곽과 음각을 검수합니다.

## 4. 색상 제안

아래 값은 목업의 시각적 분위기를 바탕으로 한 **제안값**입니다. 실제 목업 코드에서 추출한 확정값이 아닙니다.

| 색상 | HEX | 사용 제안 |
|---|---|---|
| Cody Blue | #5359F5 | 주요 버튼, 선택 상태 |
| Violet | #8050F8 | 그라데이션 보조색 |
| Deep Navy | #202C48 | 제목, 어두운 배경 |
| Soft Lavender | #E8EAFE | 보조 영역 |
| Cloud | #F2F4FA | 화면 배경 |
| Ink Navy | #17233F | 본문 |
| Soft Coral | #FDE4E5 | 주의 관련 배경의 보조색 |

그라데이션 예시: `#3767F7 → #8050F8`. 로고는 우선 단색으로 사용합니다. 초록색은 앞선 초안의 제안이었으며, 이번 팔레트는 목업에 맞춘 대안입니다.

검사 결과의 정상·주의·위험·판정 불가는 브랜드 색과 별도로 설계하고 **색상, 문구, 아이콘**을 함께 사용합니다. ‘판정 불가’를 안전하다는 뜻으로 표시하지 않습니다. 실제 색 대비와 접근성은 화면 구현 후 검증합니다.

## 5. 서체와 말투

- 한글은 Pretendard 또는 SUIT 계열, 영문은 Arial 계열을 제안합니다. 서체 파일은 포함되어 있지 않으며 사용 전 라이선스를 확인합니다.
- 제목은 굵고 짧게, 본문은 충분한 크기와 행간을 사용합니다. 핵심 행동을 먼저 제시합니다.
- 위협을 과장하지 않고, 확인한 내용과 확인하지 못한 내용을 구분합니다.
- 문구 예시: “확인이 어려워요. 공식 앱에서 다시 확인해 주세요.”
- 피할 표현: “100% 안전”, “모든 사기를 차단합니다”처럼 검증되지 않은 보장.

## 6. 화면과 응용물

**앱 홈:** 현재 목업의 밝은 카드와 파랑·보라 포인트를 유지하고, UREAKA 로고는 화면 크기에 맞는 배치 시안을 별도로 검토합니다. 로고보다 검사 버튼과 결과가 우선 보이도록 합니다.

**QR 검사:** 화면 제목과 검사 단계, 판정 근거와 다음 행동을 명확히 배치합니다. 결과의 예시 데이터와 실제 동작 여부를 구분합니다.

**발표 자료:** 첫 장에 서비스명 CodySafe와 로고를 함께 배치하고, 팀 유레카와의 관계를 설명합니다. 기능과 성능은 실제 구현 및 검증 상태에 맞춰 표기합니다.

**포스터:** “찍기 전에, 한 번 더 살피다”를 주 문구로 사용하고 QR을 확인하는 행동을 간결하게 안내합니다. 실사용 QR을 넣기 전 대상 주소를 확인합니다.

## 7. 확정 전 확인 사항

1. UREAKA 로고와 CodySafe 서비스명 병기 형태 및 방패 아이콘의 역할.
2. 실제 목업의 색상 코드, 서체와 접근성.
3. 축약 심볼 및 앱 아이콘 제작과 작은 크기 테스트.
4. 화면·인쇄물 실제 크기에서 로고 음각과 곡선 검수.
5. 서비스 구현 및 검증 상태에 맞춘 문구 최종 확인.

기준 자료: 사용자가 제공한 카멜레온 UREAKA 로고, CodySafe 목업 및 [CodySafe 저장소 README](https://github.com/rla8127/CodySafe/blob/main/README.md).
