# 임대 GPU·모델 목록 (PPT ⓒ·ⓓ·ⓕ용, 2026-11-01 10:3x 기준)

실제로 쓴 것만 적었다(정직성 원칙). 대회 L4·H100·L4(Modal)는 쓰지 않았다. 수치 근거는 `eval/gpu_latency.md`, `eval/tts_voice_tuning.md`.

## 0. 왜 이렇게 골랐나

### 0-1. GPU: 대회 제공 L4 대신 Modal NVIDIA L40S

| 항목 | 대회 제공 L4 (gp1l4-g3) | Modal NVIDIA L4 | **Modal NVIDIA L40S (사용)** |
|---|---|---|---|
| 쓸 수 있었나 | **아니오.** 접속에 VPN OTP가 필요한데 팀이 받지 못해 11-01 새벽 내내 접속 불가(결정 D-1101-1) | 예 | 예 |
| 세대·FP8 | Ada Lovelace, FP8 지원 | 같음 | Ada Lovelace, FP8 지원 |
| GPU 메모리 | 24GB | 24GB | **48GB**(실측 총 46,068MiB) |
| 메모리 대역폭(제조사 사양) | 약 300GB/s | 약 300GB/s | 약 864GB/s(약 2.9배) |
| 값 | 대회 제공 | US$0.80/시 | US$1.95/시 |

- 왜 임대 GPU인가: 대회 L4는 VPN OTP 문제로 쓸 수 없었다. GCP는 GPU 쿼터가 0이었다. Modal은 쓸 때만 켜지고(5분 쉬면 0, 비용 0), 바로 HTTPS 주소와 토큰 인증을 주며, 무료 크레딧(월 US$30) 안에서 쓸 수 있었다.
- 왜 L4가 아니라 L40S인가(호연 지시 11-01 05:3x "L4에 맞출 필요 없이 가장 좋은 성능"):
  - A. 메모리 대역폭이 L4의 약 2.9배다(제조사 사양). LLM이 글자를 내는 속도는 대역폭의 영향을 크게 받는다. L40S 실측: 판정 응답 중앙 0.66초(n=20)로 목표(첫 토큰 2초 안)를 넘었다. **L4에서는 재지 않아 비교 수치는 없다.**
  - B. 48GB라 한 장에 판정 LLM(가중치 약 9GB + 대화 기억 공간)이나 음성 모델 3개(실측 7.3GB)를 넉넉히 올리고, 768px 영상 생성도 한 장에서 돌렸다. 24GB인 L4에서 같은 구성이 되는지는 시험하지 않았다.
- 왜 H100이 아닌가: 값이 2배(US$3.95/시)인데, 판정 첫 토큰이 2초 안이라는 기준을 L40S로 이미 넘었다(중앙 0.27초).
- 정직성: PPT·README에는 "Modal의 NVIDIA L40S에서 직접 서빙"만 적는다. 대회 L4나 Modal L4에서는 돌리지 않았다.

### 0-2. 모델별 고른 이유

| 모델 | 고른 이유 | 견준 것·버린 것 |
|---|---|---|
| Kanana 1.5 8B (카카오) | 한국어에 강한 국내 오픈 모델, Apache-2.0(서비스 사용 가능), 8B라 FP8로 GPU 한 장에 충분. 판정 JSON 형식 깨짐 0/20이라 대안으로 바꿀 필요 없었음 | Qwen3.5-9B(형식 깨짐이 10%를 넘으면 바꾸기로 했던 대안, 쓰지 않음). 상용 API는 '직접 서빙' 취지에 맞지 않아 쓰지 않음 |
| whisper-large-v3-turbo | 팀 탐지 STT 서버(김동현)와 같은 모델이라 탐지와 훈련의 인식 결과가 같은 기준. 팀 비교 평가에서 숫자 정규화 CER 1.41%로 large-v3와 같고 처리 시간이 짧음 | large-v3(느림), Qwen3-ASR(팀 평가에서 누락·반복) |

| Qwen3-TTS 1.7B Base | VoiceDesign이 대사마다 목소리를 새로 만들어 같은 상대 목소리가 바뀌는 문제(호연 확인)를 고치려고, 한 번 설계한 목소리로 모든 대사를 읽게 함. 화자 유사도 0.960 → 0.993 | 말투 지시는 잃음(빠르기로만 반영) |
| Z-Image-Turbo | 세상에 없는 얼굴을 만들어 실제 인물 동의 문제가 없음. Apache-2.0, 장당 약 4초 | FLUX.1 schnell(약관 동의가 필요한 gated 모델이라 버림), 호연 본인 사진(개인 얼굴이 공개 저장소·클라우드에 남아 버림) |
| EchoMimicV3 (+ Wan2.1-Fun 1.3B, chinese-wav2vec2) | 사진 1장과 음성으로 말하는 영상. Apache-2.0 오픈 모델이라 GPU에서 직접 돌리고 설정(입 모양 강도·구간 이어 그리기)을 우리가 조정. 바탕 모델과 음성 인코더는 Flash 공식 구성 | Kling 같은 생성 플랫폼(담당 팀원 부재, 버튼 호출에 가까움), LivePortrait+MuseTalk(대안, 쓰지 않음) |
| vLLM | OpenAI 호환 주소, JSON 스키마 강제 출력, FP8 양자화를 한 번에 제공 | — |

| 구성 | 어디서 | 비고 |

| 탐지 STT | 팀 korean-stt 서버(김동현, EC2 CPU, whisper large-v3-turbo INT8) | 훈련 STT와 같은 모델 계열. 시연 때 훈련 STT도 이 서버를 씀(호연 11-01 10:1x 결정) |

## 5. 한 줄 설명 (발표용)

- "팀이 고른 오픈 모델 6종을 임대 GPU(Modal, NVIDIA L40S)에 직접 올려, 판정·음성 인식·음성 합성·딥페이크 영상을 만들었다. 시연은 GPU로 미리 만든 결과(대사 음성·판정·영상)를 저장해 두고 재생해, GPU 연결 없이도 같은 자료가 나온다. 말소리 인식(STT)만 팀 STT 서버 연결이 필요하다."
- "목소리는 녹음 없이 글 설명으로 설계했고, 영상 얼굴은 세상에 없는 사람이다. 모든 영상에 'AI 생성'을 표시했다."
