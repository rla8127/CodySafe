# CodySafe

> AI 사기는 미리 경험하고, 피해도 미리 예방한다.
> 국민 AI 사기 대응력 향상을 위한 체험형 예방/실시간 방어 플랫폼

모바일 앱 형태의 웹 MVP입니다. 빌드 없는 정적 HTML/CSS/JS로 되어 있습니다.

## 실행

```bash
cd ~/CodySafe
python3 -m http.server 8090      # 또는: pm2 start "python3 -m http.server 8090" --name codysafe
# http://<서버IP>:8090
```

- 데스크톱: 왼쪽에 소개 패널과 기능 1~12 바로가기, 오른쪽에 폰 목업이 나옵니다.
- 모바일(폭 500px 이하): 폰 프레임 없이 앱처럼 전체 화면으로 표시됩니다.

## 구조

```
index.html          진입점 (Pretendard·lucide 아이콘 CDN)
css/style.css       디자인 토큰 + 전체 스타일
js/data.js          목업 데이터 (공인 도메인 DB, 시나리오, 제보, 코파일럿 답변)
js/app.js           해시 라우터 + 화면 + 인터랙션
assets/gov-badge.svg  정부·공공기관 공인 배지 (자체 디자인, 공식 정부 상징 아님)
assets/logo.svg
```

## URL 탐지: RAG가 아니라 RDB + 규칙/유사도

URL 판정은 "이 도메인이 공인 목록에 있느냐, 공인 도메인과 얼마나 비슷하냐"를 따지는 정확 매칭 문제입니다. 의미 검색인 RAG는 맞지 않고, 관계형 DB(RDS PostgreSQL 등)에 화이트리스트와 블랙리스트를 두는 편이 정답입니다.

```
입력 URL → 도메인 정규화(punycode·www·서브도메인 제거)
  ├─ 화이트리스트(RDB): 정부(.go.kr/gov.kr), 공공(.or.kr 등록기관), 금융위 등록 금융사, 주요 기업
  │     → 일치하면 "정부 공인" 배지
  ├─ 블랙리스트(RDB/Redis): KISA 피싱 DB, 경찰청 신고, 사용자 제보(기능 5) 중 검증된 것
  ├─ 유사도 엔진: 편집거리(Levenshtein), 동형문자(0↔o, 1↔l, rn↔m), 브랜드명 포함 여부
  ├─ 평판: WHOIS 생성일, 의심 TLD, SSL, 단축 URL 펼치기
  └─ (선택) LLM: 문자 본문의 스미싱 문구 판단
```

- MVP의 [js/app.js](../js/app.js) `analyzeUrlText()`에 화이트리스트 대조, 편집거리, 동형문자, 브랜드 사칭, TLD, 경로, 문구 규칙이 실제로 구현돼 있습니다.
- RAG는 기능 8(코파일럿)과 기능 11(기관 사칭 검증)에 맞습니다. 기관 업무 지침이나 보도자료처럼 문서형 지식을 근거로 답할 때 씁니다.
