# CodySafe

> AI 사기는 미리 경험하고, 피해도 미리 예방한다.
>
> 코디세이 AI 해커톤 2026 · 팀 유레카 · 주제 02 「AI 기반 정보보호 서비스」

AI 사기를 체험으로 배우고 의심스러운 문자와 링크를 검사하는 모바일 앱 형태의 웹 MVP입니다. 빌드 없는 정적 HTML/CSS/JS로 되어 있습니다.

**상태 (2026-10-31 기준):** 화면 13개 중 **실제 판정 로직이 있는 것은 URL 탐지뿐**이고, 나머지는 예시 데이터로 만든 화면 시안입니다. AI 모델은 아직 연결하지 않았습니다.

## 실행

```bash
git clone https://github.com/rla8127/CodySafe.git
cd CodySafe
python3 -m http.server 8090
# http://localhost:8090
```

- 데스크톱: 왼쪽에 소개 패널과 기능 바로가기, 오른쪽에 폰 목업이 나옵니다.
- 모바일(폭 500px 이하): 폰 프레임 없이 앱처럼 전체 화면으로 표시됩니다.
- 인터넷 연결이 필요합니다. 폰트와 아이콘을 CDN에서 불러옵니다.
- 위 명령은 `.git`을 포함한 폴더 전체를 내보내므로 로컬 확인용으로만 쓰세요. 공개 서버에는 사이트 파일만 배포해야 합니다.

## 구조

```
index.html          진입점
css/style.css       디자인 토큰 + 전체 스타일
js/data.js          예시 데이터 (공인 도메인 목록, 시나리오, 제보, 코파일럿 답변, 점검 항목)
js/app.js           해시 라우터 + 화면 + 인터랙션
assets/             로고, 공인 배지 (자체 디자인, 공식 정부 상징 아님)
docs/brand/         브랜드 가이드와 로고
docs/project-plan.md        「찍기 전에」 QR 판독 기획안 (팀 합의 전 제안)
docs/team-plan-readme.md    위 기획의 소개 문서
```

| 9 | 가족 보호 네트워크 (확장) | `#/family` | 가족 상태, 알림 타임라인, 보호 설정 | 시안 |

## URL 탐지

[js/app.js](js/app.js)의 `analyzeUrlText()`가 브라우저에서 실행되며, 입력한 내용을 서버로 보내지 않습니다.

**구현된 검사:** 공인 도메인 목록 대조, 편집거리, 동형문자(0↔o, 1↔l, rn↔m), 브랜드명 사칭, 단축 URL, IP 주소, 퓨니코드, 의심 최상위 도메인, 경로, 스미싱 문구.

**아직 구현되지 않은 것:**

- KISA 피싱 DB 조회와 WHOIS 조회. 분석 단계 문구에 나오지만 실제로 조회하지 않습니다.
- 결과 화면의 도메인 생성일, KISA 신고 건수, 인증서 상태. 실제 조회값이 아닌 고정 표시입니다.
- 공인 도메인 목록은 20개뿐인 예시이며, 목록에 없는 사이트는 정상이어도 "주의"로 나옵니다.

**서비스로 만들 때의 구조:** URL 판정은 공인 목록에 있는지, 공인 도메인과 얼마나 비슷한지를 따지는 정확 매칭 문제라 RAG보다 관계형 DB가 맞습니다. RAG는 기관 업무 지침처럼 문서를 근거로 답하는 코파일럿(8)과 기관 사칭 검증(11)에 어울립니다.

```
입력 URL → 도메인 정규화(punycode·www·서브도메인 제거)
  ├─ 화이트리스트(RDB): 정부(.go.kr/gov.kr), 공공(.or.kr 등록기관), 금융위 등록 금융사, 주요 기업
  ├─ 블랙리스트(RDB/Redis): KISA 피싱 DB, 경찰청 신고, 검증된 사용자 제보(기능 5)
  ├─ 유사도 엔진: 편집거리, 동형문자, 브랜드명 포함 여부
  ├─ 평판: WHOIS 생성일, 의심 TLD, SSL, 단축 URL 펼치기
  └─ (선택) LLM: 문자 본문의 스미싱 문구 판단
```
