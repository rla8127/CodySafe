# CodySafe

> AI 사기는 미리 경험하고, 피해도 미리 예방한다.
>
> 코디세이 AI 해커톤 2026 · 팀 유레카 · 주제 02 「AI 기반 정보보호 서비스」

CodySafe는 **부모님이 딥페이크·피싱 사기를 안전하게 미리 겪어 보고(사기 백신), 얼마나 잘 대응했는지 채점받는** 가족 사기 예방 플랫폼입니다. 의심스러운 문자·링크 검사와 가족 보호 기능이 함께 들어 있습니다. 지금은 빌드 없는 정적 HTML/CSS/JS 웹 MVP입니다.

**상태 (2026-10-31 기준):** 화면 13개 중 실제로 동작하는 것은 URL 탐지(규칙 기반)와 사기 시뮬레이션(대본형 체험)입니다. 나머지는 예시 데이터로 만든 화면 시안이고, AI 모델은 아직 연결하지 않았습니다. 아래 '사기 백신' 절은 이번 해커톤에서 만들 계획입니다.

## 핵심: 사기 백신 (모의 사기 훈련)

회사 보안팀이 직원에게 가짜 해킹 메일을 보내 보는 '피싱 모의훈련'을 가족에게 옮긴 것입니다. 부모님이 실제 수법 그대로의 가짜 사기를 겪고, 바로 해설과 점수를 받습니다.

| 단계 | 무엇을 |
|---|---|
| 1 준비 | 자녀가 상황을 고름(가족 사칭, 기관 사칭, 사고 합의금 등) |
| 2 가짜 사기 | 부모님 화면에 **미리 녹화한 딥페이크 영상 메시지** 또는 **녹음된 피싱 전화**가 옴 |
| 3 부모님 대응 | 장면마다 부모님이 답함(송금하려 함 / 인증번호 말하려 함 / 되물음 / 끊고 저장된 번호로 다시 걸기) |
| 4 공개와 해설 | "훈련이었어요" → 몇 번째 장면에서 어떤 속임수(사칭·겁주기·비밀 요구·인증번호 요구)였는지 타임라인 |
| 5 채점과 다시 | 대본 기준으로 대응 점수를 매기고, 다른 상황으로 한 번 더 해 전후 점수 비교 |
| 6 마무리 | 가족 확인 암호 정하기, 자녀에게 결과 요약 |

### 딥페이크: 실시간이 아니라 녹화 영상으로 훈련
- 실제 사기에서는 AI로 만든 가짜 얼굴 영상을 미리 만들어 보내는 방식이 쓰입니다(예: 중국에서 AI로 만든 '가짜 소년' 영상이 노인의 동정심을 사 돈을 뜯어낸 사례, [JTBC 2026-10-21](https://youtu.be/DBSd4jk4200)).
- CodySafe도 **피싱 대본을 바탕으로 미리 녹화한 딥페이크 영상**을 훈련 재료로 씁니다. 실시간 얼굴 합성은 하지 않습니다.

### 피싱 목소리: 녹음된 대본으로 채점, 실시간은 다음 단계
- 피싱 전화는 **장면 지도(대본 그래프)**로 녹음해 둡니다. 부모님 대답에 따라 다음 장면이 갈립니다.

```
[1 사고 알림] "엄마, 나 사고 났어…"
   ├─ 걱정함 ─────────────→ [2 합의금 요구]
   ├─ "너 누구니?" 되물음 ──→ [1-1 얼버무리기]
   └─ 끊고 다시 걸기 ──────→ [성공 종료]
[2 합의금 요구]
   ├─ 보내려 함 ───────────→ [3 인증번호 요구]
   ├─ 가족 암호 질문 ──────→ [성공 종료: 사기범이 대답 못 함]
   └─ 끊고 다시 걸기 ──────→ [성공 종료]
[3 인증번호 요구] → 숫자를 말하려 하면 그 순간을 기록하고 종료
```

- 장면이 정해져 있어서 "몇 번째 장면에서 끊었나", "인증번호를 말하려 했나"로 **대응 점수를 공정하게** 매길 수 있습니다.
- 부모님 대답 판정: 우리가 학습한 분류 모델이 대답을 '정보 제공 시도·송금 순응·되물음·암호 질문·끊음·정상'으로 나눕니다(계획).
- 인증번호 유출은 **미끼 번호**로 확실하게 잡습니다. 훈련 화면에 우리가 만든 가짜 인증번호를 띄우고, 부모님이 그 숫자를 말하면 유출로 판정합니다(계획).
- 사기범 목소리로 실시간 대화하는 훈련은 다음 단계로 둡니다.

### 왜 대본으로 묶나
1. 안전: AI가 아무 말이나 하면 공개 저장소가 '사기 대본 생성기'가 됩니다. 정해진 장면 안에서만 말합니다.
2. 안정: 시연이 매번 같은 흐름으로 끝까지 갑니다.
3. 측정: 장면이 정해져 있어야 훈련 전후 점수를 비교할 수 있습니다.

## 기능과 구현 상태

| # | 기능 | 라우트 | 현재 동작 | 상태 |
|---|------|--------|----------|------|
| 1 | AI 이미지 진위 분석 | `#/image` | 업로드/샘플 → 스캔 애니메이션, 히트맵·마커, 판별 근거 | 시안 |
| 2 | AI 음성 탐지 | `#/voice` | 수신 화면 → 합성 확률 게이지, 음성 특징 근거 | 시안 |
| 3 | 실시간 통화 사기 탐지 | `#/call` | 자막 재생, 위험도 상승, 70% 이상이면 전체 화면 경고와 진동 | 시안 |
| 4 | **AI 사기 시뮬레이션 (사기 백신)** | `#/sim`, `#/play/:id` | 메신저형 대화 6종, 선택별 피드백, 결과 점수 | **시나리오 체험 동작**, 녹화 딥페이크 영상·녹음 피싱 전화·대응 채점은 개발 예정 |
| 5 | 국민 참여형 제보 | `#/report` | 필터, 추천, 검증 상태, 제보 작성 시트 | 시안 (저장 안 됨) |
| 6 | 개인 취약점 분석 | `#/weakness` | 레이더 차트, 유형별 점수, 판단 패턴 | 시안 (훈련 채점 결과와 연결 예정) |
| 7 | 맞춤형 훈련 | `#/training` | 연속 기록, 취약 유형 기반 미션, 배지 | 시안 |
| 8 | 대응 코파일럿 | `#/copilot` | 키워드에 맞는 단계 안내, 112·1332·118 바로 걸기 | 고정 답변, LLM 미연결 |
| 9 | 가족 보호 네트워크 | `#/family` | 가족 상태, 알림 타임라인, 보호 설정 | 시안 (훈련 결과 요약을 자녀에게 보내는 곳) |
| 10 | 스미싱·피싱 URL 탐지 | `#/url` | 공인 도메인 대조, 철자 유사도, 위험 점수 | **규칙 기반 구현** (일부 표시값은 아래 참고) |
| 11 | 기관 사칭 사실 검증 | `#/verify` | 기관별 공식 사실 대조, 대표번호 비교 | 키워드 규칙, 고정 데이터 |
| 12 | 신종 시나리오 자동 생성 | `#/generate` | 생성 파이프라인 애니메이션, 결과 체험 | 시안 |
| 13 | 방어 설정 점검 | `#/checkup` | 항목별 점수, 설정 안내 시트, "켰어요" 반영 | 시안 (기기를 실제로 읽지 않음) |

화면에 보이는 점수, 통계, 사용자 이름은 모두 예시입니다.

## 실행

```bash
git clone https://github.com/rla8127/CodySafe.git
cd CodySafe
python3 -m http.server 8090
# http://localhost:8090
```

- 데스크톱: 왼쪽에 소개 패널과 기능 바로가기, 오른쪽에 폰 목업이 나옵니다.
- 모바일(폭 500px 이하): 폰 프레임 없이 앱처럼 전체 화면으로 표시됩니다.
- 인터넷 연결이 필요합니다. 폰트와 아이콘을 CDN에서 불러옵니다.
- 위 명령은 `.git`을 포함한 폴더 전체를 내보내므로 로컬 확인용으로만 쓰세요. 공개 서버에는 사이트 파일만 배포해야 합니다.

## URL 탐지

[js/app.js](js/app.js)의 `analyzeUrlText()`가 브라우저에서 실행되며, 입력한 내용을 서버로 보내지 않습니다.

**구현된 검사:** 공인 도메인 목록 대조, 편집거리, 동형문자(0↔o, 1↔l, rn↔m), 브랜드명 사칭, 단축 URL, IP 주소, 퓨니코드, 의심 최상위 도메인, 경로, 스미싱 문구.

**아직 구현되지 않은 것:**

- KISA 피싱 DB 조회와 WHOIS 조회. 분석 단계 문구에 나오지만 실제로 조회하지 않습니다.
- 결과 화면의 도메인 생성일, KISA 신고 건수, 인증서 상태. 실제 조회값이 아닌 고정 표시입니다.
- 공인 도메인 목록은 20개뿐인 예시이며, 목록에 없는 사이트는 정상이어도 "주의"로 나옵니다.

**확장 후보:** QR 코드 탭에 「찍기 전에」 판독(덧댄 스티커 탐지, 인쇄물 기관명과 실제 주소 대조)을 붙이는 안이 [docs/project-plan.md](docs/project-plan.md)에 있습니다.

## 안전 설계

- 훈련용 얼굴·목소리는 당사자 동의 없이 만들지 않고, 훈련 뒤 삭제하며 공개 저장소에 올리지 않습니다.
- 훈련 화면에 '모의훈련' 표시, 끝나자마자 공개, 딥페이크 영상에는 AI 생성 표시를 넣습니다.
- 납치·폭력 장면은 넣지 않고, 실제 계좌·링크는 출력하지 않습니다.
