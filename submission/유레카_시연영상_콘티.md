# 시연 영상 콘티 (2분 이내, MP4, 1080p 이상)

필수 요건: 실제 동작 화면 녹화, 입력부터 결과까지 연결, 글자 판독 가능. 슬라이드만 있는 영상은 인정되지 않습니다.
2분을 넘으면 뒷부분은 평가되지 않으니 1:55를 목표로 합니다.

| 시간 | 화면 | 자막 또는 내레이션 |
|---|---|---|
| 0:00–0:10 | 랜딩 첫 화면 | 전화를 끊은 뒤에도 피해는 이어집니다. CodySafe는 그다음을 가족과 함께 막습니다. |
| 0:10–0:25 | 폰: 검사 탭, 녹음 폴더 "연결됨" | 앱은 직접 녹음하지 않고, 삼성 통화 녹음 폴더의 새 파일만 읽습니다. |
| 0:25–0:50 | 폰: 테스트 통화 업로드 → 음성 변환 중 → 분석 중 (대기 구간은 "시간 단축" 표시) | 음성을 글자로 바꾸고, 비슷한 사례를 찾아 AI가 판정합니다. |
| 0:50–1:05 | 폰: "지금 돈을 보내지 마세요" 경고 | 강한 의심이면 바로 멈추라고 알리고 112로 연결합니다. |
| 1:05–1:20 | 폰: 결과 카드의 "녹취에서 확인한 말" | AI가 근거로 든 문장이 실제 녹취에 있는지 코드로 대조해, 있는 말만 보여 줍니다. |
| 1:20–1:35 | 폰: 금융 앱 실행 → 경고 화면으로 복귀 | 잠금 중에는 금융 앱과 원격제어 앱 47개를 막습니다. |
| 1:35–1:48 | 두 번째 기기 또는 웹: 가족 알림과 암구호, 잠금 해제 | 가족에게는 의심 여부만 갑니다. 통화 내용은 보이지 않고, 암구호로 확인한 뒤 풀어 줍니다. |
| 1:48–1:55 | 웹: 사기 체험 또는 제보 한 컷, 로고 | 체험과 제보로 다음 사기에도 대비합니다. |

## 촬영 전 확인

- 테스트 통화만 사용합니다. 실제 이름, 번호, 계좌가 화면에 나오면 안 됩니다.
- 기존 `server/web/media/demo.mp4`는 16초, 540x1064 세로 영상이라 그대로 내면 권장 해상도에 못 미칩니다. 새로 녹화하세요.
- 시간을 줄인 구간은 자막으로 밝힙니다.
- "탐지율 몇 %"처럼 측정하지 않은 수치는 말하지 않습니다.
